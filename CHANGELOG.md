## [0.1.0] - 2024-12-02

### Added
- Initial commit with core functionality
- CompanySearch script for identifying corporate property owners
- DBFexporter for converting .dbf to .csv
- detect_outliers for statistical analysis of property valuations
- gen_json for creating JSON from LandCodes metadata
- geoextract for calculating polygon centroids
- hexplot for creating hex bin visualizations by zoning code
- hist_plotter for histogram visualizations
- intloader for data type conversion
- sanitizer for normalizing owner names
- SQLite database (LR.db) with PAGIS property data
- Documentation structure
- Test directory structure
